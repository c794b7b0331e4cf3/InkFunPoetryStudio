# AI 赋能

> 本项目采用 “业务服务封装 + 统一模型调用适配服务层” 方式实现，而非直接依赖官方 SDK。  
> 后端在业务服务中构造提示词与上下文，通过自定义适配层发起模型请求，获取结果后进行结构化处理、规则校验与业务回写，最终在创作流程中向用户提供智能建议与生成能力。

# 架构

> 本系统采用现代全栈单体架构:  
> 以 Laravel 作为统一应用内核，结合 Inertia 实现前后端协同的混合渲染体验;  
> 在单体内部通过 Controller 层进行业务模块化，并将 AI 能力以 Service 方式嵌入创作流程，形成 “可快速迭代、易于治理、对业务友好” 的工程形态。

# 关键算法

## 墨水屏

> 墨水动态效果本质上是一个 GPU 流体模拟。  
> 算法在二维速度场上按帧迭代，核心流程如下：

- 平流（Advection）：按当前速度场回溯采样，推动“墨水”随流动扩散，并通过 BFECC 减少数值耗散。
- 外力注入（External Force）：将鼠标或触摸位移映射为局部力场，形成可交互的“搅动”效果。
- 粘性扩散（Viscous）：通过多次迭代平滑速度场，模拟墨水黏滞感。
- 散度-压力求解（Divergence + Poisson + Pressure）：先计算散度，再迭代求压力并回写速度，约束流体近似不可压缩，避免画面“鼓胀”。
- 颜色映射渲染：将速度大小映射到调色板，实现流速越强颜色越明显的视觉层次。
